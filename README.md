# Blog-Api-Laravel

FlickNest API is a platform where users can create profiles, log the movies and TV shows they've watched, and explore new content. It provides seamless integration for building personalized watchlists and sharing viewing experiences with others.

## Technologies (languages & frameworks)

- Php
- Laravel
- MySql

## Setup

1. Install Php Packages
```sh
composer install
```
2. Create .env File
```sh
1. duplicate the ".env.example" in main folder
2. rename the file you copied to ".env"
3. configure the ".env" file you renamed
```
3. Create App Key
```sh
php artisan key:generate
```
4. Run Migrations
```sh
php artisan migrate
```
5. Run Seeders (For Test Datas)
```sh
php artisan db:seed
```
6. Run Laravel Project
```sh
php artisan serve
```
